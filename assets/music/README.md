# Nhạc nền cho story.video

Thả file nhạc **KHÔNG BẢN QUYỀN** (.mp3/.m4a/.wav/.ogg) vào thư mục này.
`story.video` sẽ tự trộn nhẹ (âm lượng ~14%) dưới giọng đọc để video đỡ trơ.

- Trống thư mục = video chỉ có giọng (không lỗi).
- Có nhiều file = lấy file đầu theo thứ tự tên (đặt tên `01_...` để ưu tiên).

## Nguồn nhạc free an toàn bản quyền
- YouTube Audio Library (Studio → Âm thanh) — tải về, lọc "Không cần ghi công".
- Pixabay Music, Incompetech (Kevin MacLeod, CC-BY — nhớ ghi công), PeriTune (CC-BY).

⚠️ Nếu track yêu cầu ghi công (CC-BY), nhớ thêm dòng credit vào mô tả video.
